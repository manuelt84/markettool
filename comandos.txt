Configurar el Proyecto en PowerShell
$env:GOOGLE_CLOUD_PROJECT="trading-449607"; gcloud config set project trading-449607

Autenticación con GCP
gcloud auth login && gcloud auth configure-docker && gcloud auth application-default login

Habilitar la API de Kubernetes Engine
gcloud services enable container.googleapis.com

Construir y Subir la Imagen a Container Registry
docker build -t markettool .
docker tag markettool:latest southamerica-west1-docker.pkg.dev/trading-449607/trading-repo/markettool:latest
docker push southamerica-west1-docker.pkg.dev/trading-449607/trading-repo/markettool:latest

Crear el Cluster en GKE
#CREAR CLUSTER c2-standard-8 (8 vCPUs, 32GB RAM) – si quieres más memoria.  Aqui los nodos pueden crecer, por ende los discos tambien
gcloud container clusters create trading-cluster --zone=southamerica-west1-a --num-nodes=1 --machine-type=c2-standard-8 --enable-autoscaling --min-nodes=1 --max-nodes=5 --enable-ip-alias --preemptible

#Esto es para reducir el numero de nodos (se ve reflejado en menor numero de discos)
gcloud container clusters resize trading-cluster --node-pool=default-pool --num-nodes=1 --zone=southamerica-west1-a


Obtener Credenciales para el Cluster
gcloud container clusters get-credentials trading-cluster --zone=southamerica-west1-a


kubectl get services markettool
Verificar el Estado del Despliegue
kubectl get pods && kubectl get services && kubectl get deployments


gcloud container clusters list
gcloud container clusters get-credentials trading-cluster --zone=southamerica-west1-a
kubectl get nodes
